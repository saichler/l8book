Contract first

Interfaces and protobuf models establish a stable foundation before infrastructure or application concerns.

Distributed by design

Discovery, routing, replication, caching, transactions, and live browser updates are framework capabilities.

Composable delivery

Projects select shared services and, when needed, add the observation pipeline without rebuilding the core.
